# MWL Beta 2.1.0 배포 기록

2026-11-19. 대표님이 선택한 Aurora Halo 10-5번 디자인과 Spring Touch 모션의 공통 앱 적용.

## 변경

- SUIT 로컬 글꼴과 짙은 남청·청록·푸른 보라의 Aurora Halo 팔레트를 앱 전반의 헤더, 카드, 버튼, 입력창, 시트, 하단 탐색에 적용.
- 홈에서 빠른 기록을 오늘 한눈에 보기보다 위에 배치. 버튼을 낮추고 실제 몸·식단·운동 기록을 요약 카드에 표시.
- 이모지 기반 하단 탐색을 동일한 선형 SVG 아이콘으로 교체하고 중앙 빠른 기록 버튼을 배치.
- Spring Touch를 화면 진입, 팝업 진입, 토스트, 버튼 눌림과 호버에 적용. `prefers-reduced-motion` 사용자의 동작은 최소화.
- 웹과 Android가 같은 HTML/CSS/JS 자산을 사용. Android versionCode 9.
