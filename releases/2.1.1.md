# MWL Beta 2.1.1 배포 기록

2026-11-19. 대표님이 확정한 여백을 넓힌 05번 아이콘을 웹과 Android에 적용.

## 변경

- 같은 SVG 원본을 웹 favicon·헤더, PWA 192/512px, iPhone 홈 화면 180px 아이콘에 사용.
- Android 기본 런처 아이콘과 기본 시작 화면을 새 심볼로 교체. Adaptive icon은 투명 전경을 중앙 안전 영역에 배치.
- 앱 버전 `2.1.1-beta`, Android versionCode 10. 화면 구조와 기록 데이터 형식은 변경하지 않음.

- 자동 테스트 115개 중 114개 통과, 에뮬레이터 전용 1개 건너뜀.
