# MWL Beta 2.0.0 배포 기록

상태: 웹·APK 빌드와 공개 배포 검증 완료. 실제 승인 사용자 두 계정의 사진 기반 종단 간 시험은 별도다.

## 변경

- 계정별 AI 초안 검토함과 외부 AI 도구 연결.
- AI가 만든 음식 추정 범위를 사용자에게 표시.
- 식단·운동·몸·개인 도감의 AI 초안 확정 경로.
- 앱 내 AI API 호출 없이 Codex·Claude Code에서 재사용 가능한 로컬 MCP 연결 도구.
- 머신 신규 초안에 전체·명판 사진 메타데이터와 제조사·모델 확인 요구.
- 웹·Android 공통 화면에 AI 연결과 검토함 진입점 추가.

## 검증 및 배포

- 자동 테스트: 앱 107건 중 106건 통과·1건 일반 실행에서 건너뜀, 연결 도구 7건 통과.
- Firestore 권한 테스트: 에뮬레이터에서 두 승인 계정의 기록·AI 초안 교차 접근 거부 및 초안+기록 거래 확정 통과. 공개 규칙 배포 완료.
- 390/768/1200px 시각 검수: 8개 화면 가로 넘침·8px 미만 주요 카드 간격 없음. 예시 식단 초안의 검토함을 세 화면 폭에서 확인.
- Android 에뮬레이터: Beta 2.0.0 APK 설치·실행, 홈·AI 검토함·설정 화면 확인. 승인 전 계정이므로 실계정 초안 확정은 미검증.
- 웹 공개: commit `1b746ac`의 GitHub Actions [배포 작업](https://github.com/studiohooje/MyWeightLog/actions/runs/44287461635) 성공. [공개 사이트](https://studiohooje.github.io/MyWeightLog/)에서 Beta 2.0.0 HTML·AI 검토함 스크립트 HTTP 200 확인. 이후 APK 다운로드 링크를 추가하는 후속 커밋을 별도로 검증한다.
- APK: `MWL-Beta-2.0.0-debug.apk`, SHA-256 `17F5FB51B3D92052CCBA52640C8AEA5F1175E8289C843CF5CB05306AF33C0391`.
- 친구 실계정 시험: 미실행

## 현재 시험 경계

- AI 연결은 같은 컴퓨터의 브라우저와 로컬 MCP 도구를 일회성 코드로 짝짓는 방식이다. 단기 사용자 토큰은 도구 메모리에만 보관하며 만료 시 다시 연결한다.
- AI 대화의 사진 원본은 서버에 저장되지 않는다. 초안에는 판정·출처 메타데이터만 저장된다.
- 실제 대표님·친구 계정의 인증과 사진을 이용한 종단 간 시험은 본인 로그인과 실사용 자료가 있을 때 완료 판정한다.
- 일반 ChatGPT 채팅만으로는 이 로컬 MCP 도구를 자동 실행할 수 없다. MCP를 실행할 수 있는 Codex·Claude Code 환경이 이번 직접 입력 시험 범위다.
