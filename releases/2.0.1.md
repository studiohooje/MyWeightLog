# MWL Beta 2.0.1 배포 기록

2026-11-19. Beta 2.0.0에서 확인한 누락을 보완하는 패치.

## 변경

- AI 식사 초안의 날짜·식사 번호·시각·음식별 영양값·추정 범위를 검토 화면에서 수정한다.
- AI 운동 초안의 운동명·머신·세트·기록 시각을 수정하고 세트를 추가·삭제한다.
- 같은 내용의 최종 기록 중복을 검사하고 확정 거래에서 같은 ID의 동시 생성을 차단한다.
- 음식 프리셋과 식사 기록에 추정 범위·근거·출처를 보존한다. 중량 변경 시 범위도 환산한다.
- 앱의 머신 등록 요청은 전체 사진과 명판 사진을 압축해 본인·관리자만 읽는 Firestore 요청 문서에 함께 보관한다. 기존 AI 대화 연결 도구는 사진 픽셀 대신 메타데이터만 전달한다.
- 개인 머신 별칭 수정, AI 검색의 머신 별칭·지점·과거 운동 포함, 검색 결과 절단 알림을 보완한다.

## 검증

- 앱 자동 테스트 115건 중 114건 통과, 1건은 일반 실행에서 에뮬레이터 전용이라 건너뜀.
- AI 연결 도구 자동 테스트 8건 통과.
- Firestore 에뮬레이터 권한 테스트 1건 통과. 승인/비승인 사용자와 사진 요청 접근을 검사했다.
- 웹 빌드와 정적 파일 검증 통과. Android 디버그 APK 빌드 성공.
- Android 에뮬레이터에서 2.0.0 → 2.0.1 덮어쓰기 설치 성공. 버전코드 8과 홈·AI 검토함 화면을 확인했다.
- 실제 두 사용자 계정의 로그인, 사진 요청, AI 도구 연결부터 기록 확정까지의 종단 간 시험은 아직 완료하지 않았다.

## 운영 경계

- 앱 내 AI 모델 API와 워치 연동은 아직 연결하지 않았다.
- Codex·Claude Code 직접 기록은 같은 컴퓨터의 로컬 MCP 연결과 해당 사용자의 승인된 Google 계정을 필요로 한다.
- 머신 사진 요청은 Firestore 문서당 크기 제한을 지키도록 앱에서 압축한다. 개인 실데이터 종단 간 시험은 별도로 수행해야 한다.
